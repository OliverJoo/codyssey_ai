## 폴더 구조

### 1. `pre_course/` (선발 과정 미션)

- `e1-1/`: Git 기초 및 협업 환경 설정
- `e1-2/`: 나만의 퀴즈 게임 콘솔 프로그램 (Python)
- `e1-3/`: Mini NPU Simulator (패턴 및 필터 행렬 MAC 연산 시뮬레이터)

### 2. `AI_SW/` (본 과정 미션)

#### `01_Basic/`

- `b1-1/`: 컴퓨터가 알아서 자기 상태를 점검하게 만들기 (Linux 프로세스 감시 및 리소스 모니터링 자동화)
- `b2-1/`: 나만의 용돈 기입장 콘솔 프로그램 (`budget_app`, 계층형 모듈화 및 TDD 기반 가계부)
- `b2-2/`: 4인 GitHub Flow 협업 실습 (Issue, Branch, PR, Code Review, Conflict Resolution 및 Git 복구 전략)
- `b3-1/`: Mini Redis 구축 (내장 컬렉션 없이 밑바닥부터 구현한 In-Memory Key-Value 저장소)
- `b3-2/mini-git/`: Python으로 구현한 모의 Git 저장소 CLI 도구 (커밋 그래프 DAG 관리 및 검색)
- `b5-1/cafe-order-mariadb/`: MariaDB 기반 카페 주문 관리 시스템 DB 설계 및 분석 쿼리 작성
- `b7-1/`: AI Chatbot 프로젝트 및 테스트 환경
