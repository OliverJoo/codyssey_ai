# codyssey_missions

- `pre_course/`: 선발 과정 미션들
  - `e1-1/`: 첫 번째 미션 (예: Git 기본)
  - `e1-2/`: 두 번째 미션 (예: Python 환경 설정)
  - `e1-3/`: 세 번째 미션 (예: 간단한 스크립트 작성)

- `AI_SW/`: 본 과정 미션들
  - `01_Basic/`
    - `b3-2/mini-git/`: Python으로 구현한 모의 Git 저장소 CLI 도구
